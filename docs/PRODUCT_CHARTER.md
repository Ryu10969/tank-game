# PRODUCT_CHARTER

Status: Draft for owner review
Last updated: 2026-09-20

## 1. Product statement

`tank-game` は、直射よりも壁を利用した跳弾を狙うことに価値を置く、短時間の見下ろし型タンクゲームである。

中核となる体験は次の一文で定義する。

> 敵戦車を撃つゲームではなく、反射角を読んで弾道を組み立てるゲーム。

## 2. Target experience

- プレイヤーは移動、照準、射撃を短時間で理解できる。
- 直射できない敵を1回以上の反射で倒せる。
- 反射回数に応じた連続音によって成功した軌道を認識できる。
- 戦車同士の戦闘だが、軍事的・殺伐とした表現にはしない。
- 木製の積み木が卓上で遊んでいるように見える。

## 3. Phase 0 goal

Webブラウザで第三者がStage 1〜10を通して遊び、跳弾がこのゲームの楽しさとして成立するかを評価できる状態を作る。

## 4. Phase 0 scope

### In scope

- Unity 6 / C# / URPによる2.5D表現
- Webビルド
- プレイヤー戦車1種類
- BOT行動基盤1種類と、Standard / Heavy / Burst / Sentryのgraybox差分
- Stage 1〜10
- 移動、照準、射撃
- 同時存在数3発の弾丸制限
- 壁面法線に基づく跳弾
- プレイヤーと標準敵の一撃撃破、Heavyの2 hit撃破
- ステージクリアとStage 1への敗北リセット
- 仮BGM、発射音、反射音、撃破音
- 最終品質基準となる木製テーマ1セット

### Out of scope

- iOS / Androidネイティブビルド
- Photon Fusionその他のオンライン通信
- PvP / CO-OP
- アカウント、クラウドセーブ
- ガチャ、課金、広告
- ランキング、シーズン、Battle Pass
- 11ステージ以上
- 複数テーマおよび量産スキン

## 5. Success criteria

Phase 0の合否は次の計測で判定する。目標値は初回プレイテスト前にプロダクトオーナーが確定する。

| Metric | 現在の状態 |
|---|---|
| 初見プレイヤーが操作説明後に射撃できるまでの時間 | 未決定 |
| Stage 3到達率 | 未決定 |
| 1回以上の跳弾による撃破率 | 未決定 |
| 1セッションの中央値 | 未決定 |
| 「跳弾が楽しい」5段階評価 | 未決定 |

未決定の目標値を実装者が推測して埋めてはならない。

## 6. Product principles

優先順位は次のとおり。

1. 跳弾の予測可能性
2. 操作への即時フィードバック
3. 画面上の視認性
4. 短時間での再挑戦性
5. 見た目の独自性
6. コンテンツ量

## 7. Non-goals

- 現実の戦車挙動の再現
- 軍事シミュレーション
- 物理演算の偶然性を楽しむゲーム
- 既存のNintendo作品を再現すること
