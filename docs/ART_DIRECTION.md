# ART_DIRECTION

Status: Draft for owner review
Last updated: 2026-09-20

## 1. Visual identity

木製の組み立て玩具が卓上の小型アリーナで戦う、温かく非軍事的な2.5D表現とする。

## 2. Mandatory properties

- Orthographic camera
- 丸みのある低ポリゴン形状
- 大きめのベベル
- 砲塔と車体を一目で区別できるシルエット
- 木目方向が部品の長軸に沿う
- マットな表面
- 柔らかい接地影
- 背景と戦車の明度差を確保
- プレイヤー、敵、弾丸を色だけでなく形状でも識別可能にする

## 3. Phase 0 asset set

- プレイヤー戦車1体
- 敵戦車1体
- 砲弾1種
- 床1種
- 直線壁、角壁、柱の3種
- Spawn表現
- 発射、反射、撃破の3 VFX
- HUD用の弾数表示

これ以外の量産アセットはPhase 0のゲーム性検証後に作る。

## 4. Forbidden direction

- 写実的な軍用車両
- 第二次世界大戦を想起させる意匠
- 血液、人体損壊、現実的な爆発被害
- Wii、Mii、Nintendo作品を想起させるUI、フォント、配色、キャラクター比率
- 既存作品のステージ構造を再現すること
- 特定の存命アーティスト名や特定作品名を生成プロンプトに含めること

## 5. Asset pipeline

1. 本文書に基づき複数のコンセプト案を作る。
2. 真上寄りのゲームカメラでシルエットを評価する。
3. 採用案からゲーム用3Dモデルを作る。
4. Blender等でTopology、UV、Scale、Pivot、部品分割を確認する。
5. Unityへ読み込み、Material、Collider、Prefabを設定する。
6. Webビルド上の見た目と負荷を確認する。

AI生成物は無審査で採用しない。使用したサービス、モデル、生成日、入力、編集内容、利用条件をアセット台帳へ記録する。

## 6. Approval gate

Stage 2以降の見た目を作る前に、Stage 1について次をプロダクトオーナーが承認する。

- カメラ角度
- 戦車の比率
- 木材色
- 背景とのコントラスト
- 壁の高さ
- 砲弾の視認性
- 影の濃さ
- 発射・反射・撃破VFX
