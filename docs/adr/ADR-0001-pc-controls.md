# ADR-0001: Phase 0 PC Controls

- Status: Accepted
- Date: 2026-09-20

## Context

Phase 0はWebブラウザ上で第三者が短時間に試せるVertical Sliceである。ゲームの判断対象は戦車特有の複雑な操縦ではなく、移動しながら反射角を読んで砲塔を向けることに置く。

車体相対の前進・後退・旋回方式は戦車らしさを増す一方、初見プレイヤーが移動と照準を同時に学ぶ負荷を増やす。Phase 0では跳弾の評価を操作習熟から分離する必要がある。

## Decision

- `W/A/S/D`で画面基準に移動する。
- 斜め入力は正規化する。
- 車体は移動ベクトルへ旋回するが、移動は旋回完了を待たない。
- マウスカーソルとゲーム平面の交点へ砲塔を向ける。
- 左クリック押下1回につき1発を要求する。
- ボタン保持による自動連射は行わない。
- タッチ入力はPhase 0のPC操作確立後に別ADRで決定する。

## Consequences

### Positive

- 移動方向と照準方向を独立させられる。
- 初見プレイヤーが跳弾判断へ集中できる。
- 人間入力を移動ベクトル、照準点、射撃要求として抽象化できる。

### Negative

- 現実の装軌車両の操作とは異なる。
- 車体が横方向へ移動できるため、アニメーションと見た目の整合性調整が必要になる。

## Rejected alternative

`W/S`で前進・後退、`A/D`で車体旋回するTank controlsはPhase 0では採用しない。跳弾そのものではなく操縦習熟が初回プレイ結果を左右するためである。
