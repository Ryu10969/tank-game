# IP_GUIDELINES

Status: Active
Last updated: 2026-09-20

## 1. Purpose

既存作品のアイデアから着想を得た場合でも、名称、表現、素材、宣伝が特定作品の複製または公式関連商品に見えないよう管理する。

## 2. Prohibited repository content

- Nintendo作品のスクリーンショット、映像、音声、モデル、テクスチャ
- Wii / Miiを想起させるキャラクター素材
- 既存作品から抽出または模写したステージ
- 既存作品のロゴ、フォント、UI、アイコン
- 出典または利用条件を確認できない素材

## 3. Naming rules

- `Tanks!`、`はじめてのWii`、`Wii Play`を商品名、サブタイトル、広告見出しとして使用しない。
- `tank-game` は開発用の仮リポジトリ名であり、販売名ではない。
- 販売名決定前にJ-PlatPatで文字列と称呼の類似検索を行う。
- 商用公開前に、名称、ロゴ、主要アート、ストア文言を知財専門家へ確認する。

## 4. Generation prompt rules

生成指示は必要な視覚要素を直接記述する。

許容例:

> miniature wooden tabletop tank, rounded construction-toy geometry, orthographic tactical arena, warm natural materials

禁止例:

> Wii Play Tanksのようにする

## 5. Asset provenance

すべての外部・生成アセットについて次を記録する。

- ファイル名
- 制作者または生成サービス
- 入手元URL
- 作成・入手日
- ライセンス名とライセンス本文の保存先
- 商用利用、改変、再配布の可否
- 生成プロンプトと人間による編集内容

権利状態を確認できないアセットはリリースビルドへ含めない。

## 6. Legal boundary

この文書は制作上のリスク管理方針であり、法的判断そのものではない。最終的な商標・著作権・不正競争防止法上の評価は専門家へ依頼する。
